# 体外诊断试剂 (IVD) 行业分类目录与合规追溯专精规范 (包含权威法条引证)

## 一、 IVD 分类目录与监管等级法条引证

根据《医疗器械监督管理条例》（国务院令第739号）及《体外诊断试剂注册与备案管理办法》（国家市场监督管理总局令第48号，2021年10月1日起施行）：

1. **第一类体外诊断试剂（备案制，依据第48号令 第九条第（一）项）**
   - 主要为通用生化试剂的基础反应介质，如样本处理液、细胞保存液、染色液等；
   - 实行市级药品监督管理部门告知性备案。

2. **第二类体外诊断试剂（注册制，依据第48号令 第九条第（二）项）**
   - 常见临床诊断试剂，如肝功/肾功生化检测试剂盒、常规激素免疫检测试剂、血细胞分析试剂等；
   - 实行省级药品监督管理部门审批注册，纳入国家第三批 UDI 重点实施范围。

3. **第三类体外诊断试剂（高风险注册制，依据第48号令 第九条第（三）项）**
   - 涉及重大传染病筛查、血源核酸检测、肿瘤标志物伴随诊断、遗传基因突变检测等；
   - 实行国家药品监督管理局（NMPA）直接注册审批，自 **2022年6月1日起** 必须全面实施 UDI 申报与赋码追溯（国家药监局2021年第114号公告）。

## 二、 IVD 试剂赋码与包装追溯特性 (依据 GMP 《体外诊断试剂附录》)

1. **多级包装结构复杂性（依据《UDI系统规则》第十一条）**
   - 通常包含：试剂瓶/试剂管（内包装单件） $\to$ 试剂盒（最小销售单元） $\to$ 中包装 $\to$ 运输大箱；
   - 必须在系统中建立严密的包装换算比例（如 1盒 = 2瓶R1 + 2瓶R2），各级赋予不同 GTIN (DI) 码。

2. **强制动态生产标识 PI（依据第48号令 第七十七条 & GS1 AI 规范）**
   - IVD 试剂受活性衰减影响大，生产标识 (PI) 中必须严格包含：
     - **`(10)` 生产批号**；
     - **`(17)` 有效期至**（严格精确到年月日）；
     - 必要时包含开封后使用期限或生产序列号。

3. **冷链物流与温湿度协同追溯（依据 GB/T 34399-2017 《医药产品冷链物流温湿度监控要求》）**
   - 必须结合冷藏车、保温箱的温湿度监控系统（2℃~8℃ 或 -20℃ 冷冻），在出入库扫码时联动验证温控记录。
