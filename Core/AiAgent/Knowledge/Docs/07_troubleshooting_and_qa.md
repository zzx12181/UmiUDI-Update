# 医疗器械生产赋码与合规质量故障智能排查指南

## 一、 重码冲突报警 (Duplicate Code Alarm)
- **现象描述**：产线打印或入库扫码时，系统弹出“当前序列号已存在/条码重复”红色报警。
- **根因分析**：
  1. 序列号计数器未设置工单级隔离锁；
  2. 操作员因扫码枪连扫或手抖重复扫描了同一件产品；
  3. 打印机断纸或卡纸后，操作员未注销废标直接重新打印。
- **处置与排查指引**：
  1. 立即隔离重复实物，在系统【赋码查询】中检索该序列号的初次生成工单与绑定记录；
  2. 若属物理废标，在系统执行【废码作废】登记；
  3. 调整打印模板计数器起始值，恢复排产。

## 二、 条码无法识别或 GS1 校验位错误
- **现象描述**：扫码枪拒读、扫码结果乱码或系统提示“GS1 Mod10 校验位错误”。
- **根因分析**：
  1. GTIN-14 最后一位校验码未按 Mod10 规则动态计算；
  2. AI 标识符（如 `(01)`、`(10)`、`(17)`）括号直接打入了条码数据区（条码中应为 FNC1 分隔符，括号仅为人眼可见字符 HRI）；
  3. 打印机 DPI 分辨率不足（如 203 DPI 打印微型 DM 码导致畸变）、碳带起皱或热敏头断针；
  4. 日期格式错误（误将 2026-09-01 编码为带横杠格式，标准必须为 6 位纯数字 `260901`）。
- **处置与排查指引**：
  1. 在系统【条码生成测试】中重新生成标准 GS1 编码串；
  2. 使用高倍放大条码检测仪（评级 ISO 15415）核对二维码对比度；
  3. 更换为 300/600 DPI 工业打印头并清洁胶辊。

## 三、 国家药监局 CUDID 申报对接错误码排查
- **错误 1001 - 机构未授权**：未在药监局对接申请菜单上传加盖公章的申请表 PDF，或授权密钥过期。
- **错误 2005 - DI 校验失败**：GTIN 码未在 GS1 官方备案，或企业前缀与申报厂商组织机构代码不匹配。
- **错误 3008 - 必填扩展属性缺失**：如无菌器械未提供灭菌方式、IVD 未提供储存条件或温控上下限。
