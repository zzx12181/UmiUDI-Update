# 国家药监局医疗器械唯一标识数据库 (CUDID) 数据对接说明与官方 API 规范指南

## 一、 官方数据对接专区概述
根据国家药品监督管理局《医疗器械唯一标识系统规则》（2019年第66号）第十三条，国家药品监督管理局医疗器械唯一标识数据库（CUDID，官方门户：https://udi.nmpa.gov.cn）为医疗器械注册人/备案人提供申报对接接口，为医疗器械流通企业、医疗机构及医保部门提供数据共享接口。

---

## 二、 官方核心规范文件体系 (国家药监局信息中心发布)

| 文档类型 | 官方文件全称 | 主要用途与核心业务规范 |
| :--- | :--- | :--- |
| **申报接口** | **《医疗器械唯一标识管理信息系统业务申报API标准文档》** | 面向注册人/备案人，规范通过 HTTPS RESTful JSON 接口自动申报、维护 DI 主数据、规格型号、包装层级及扩展属性。采用 HMAC-SHA256 签名鉴权。 |
| **共享接口** | **《医疗器械唯一标识管理信息系统数据共享API标准文档》** | 面向流通、院内及公众，提供已发布 DI 数据、全量下载及每日增量同步接口（数据基于 YY/T 1752-2020 规范）。 |
| **导入模板** | **《医疗器械唯一标识信息系统数据导入模板》** | 支持未开发系统 API 直连的企业，通过标准 Excel/XML 模板批量录入并打包上传。 |
| **申请表单** | **《国家药品监督管理局医疗器械唯一标识数据库对接申请表》** | 企业申请对接资格时必须填写的法定文件，须加盖企业公章并上传扫描件审核。 |

---

## 三、 企业接入国家 CUDID 数据库四步标准作业流程

1. **第一步：申请表下载与资质报备**
   - 企业登录 CUDID 门户（udi.nmpa.gov.cn）下载《对接申请表》；
   - 如实填写企业统一社会信用代码、系统开发商（如本系统 UmiUDI）信息、固定出口 IP 地址，加盖法定公章后上传 PDF 扫描件。
2. **第二步：审核通过并获取通信密钥**
   - 国家药监局信息中心在 3~5 个工作日内完成审核；
   - 审核通过后，企业主账号将接收到分配的 `AppKey` 与通信私钥 `AppSecret`。
3. **第三步：测试环境接口联调**
   - 调用国家药监局测试沙箱地址，验证数据映射、必填项校验及签名算法，确保上报数据 100% 符合 YY/T 1752-2020 标准。
4. **第四步：正式生产环境切换与日常维护**
   - 切换至正式环境服务地址，在产品正式上市销售前实现 UDI-DI 数据的自动化上报、变更公示及数据状态双向同步。
