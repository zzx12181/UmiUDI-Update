# UmiUDI & Drug 综合追溯系统业务标准操作规程 (SOP) 全集

> **文件编号**：SOP-UMI-2026-V3  
> **生效日期**：2026年09月01日  
> **适用范围**：医疗器械唯一标识 (UDI) 与国家药品追溯码 (DTC) 全生命周期管理系统  
> **界面交互架构**：  
> • **顶部水平导航栏（Segmented 控件）**：承载全部 **一级大类菜单**（`DI管理`、`药品管理`、`UDI管理`、`DTC管理`、`仓库管理`、`药品仓库`、`基础数据`、`权限配置`、`UDI追溯`、`ERP`、`AI助手`）；  
> • **左侧树形导航栏（Tree / Menu 控件）**：点击顶部一级菜单后，左侧动态加载并展示对应的 **二级分类分组** 与 **三级业务功能入口**；  
> • **右侧主工作区（Tab 控件）**：点击左侧功能菜单后，以多标签页（TabPage）形式并排展示业务工作台与数据表格。  
> **核心质量红线**：  
> 1. **严禁未首检批量赋码打印**：打印单在完成首检合格前，批量打印按钮被系统强制置灰锁定；  
> 2. **单据保存即为“创建”状态**：新建单据保存后状态为“创建”，流通必须由主管执行“审核”后方可下推与打印；  
> 3. **单据下推强校验防重**：销售单下推生产单、生产单下推打印单均需满足已审核状态，禁止对已关闭或已下推行二次下推；  
> 4. **双向穿透溯源闭环**：销售单可下查生产单；生产单可上查销售单、下查打印任务；打印单可一键上查来源生产工单与销售源单；  
> 5. **拆装箱总件数严格守恒**：拆解单品自动同步入库单散件台账，禁止生成虚假 TZ/HR 调整单；在库外箱严禁装入无在库库存单品。

## 核心通则：单据流转全链路下推、上查与校验规则体系

```
【销售订单 (XSD)】 
      │  [下推] 选中下推 / 整单下推 / 下推并编辑 (须已审核、未关闭、未下推)
      ▼
【生产工单 (SCD)】 ◀─── [上查] 穿透来源销售单明细 (客户、下单量、原单号)
      │  [下查] 穿透下游关联打印任务
      │  [下推] 选中下推 / 整单下推 / 包装码折算弹窗 (须已审核、未下推)
      ▼
【打印任务 (DY)】  ◀─── [上查] (全新) 穿透来源生产工单与销售客户源单
      │  [强管控] 必须首检合格 (udi_dy_ywzt="已首检") 解锁批量打印按钮
      ▼
【首检/打印/装箱/入库】
```

## 模块一：DI 产品标识数据治理规范体系 (SOP-DI 系列)

### SOP-DI-01 医疗器械产品标识 (DI) 主数据建档规程
- **1. 目的与范围**：规范国内医疗器械产品标识（DI）主数据建档操作，确保 41 项法定属性完整准确，完全符合国家药监局 CUDID V3-20260828 规范。
- **2. 真实系统操作路径**：
  * **主路径**：在【顶部导航栏】点击 **【DI管理】** ➔ 在【左侧导航栏】展开 **【其他】** 分组，点击 **【DI库（生成）】** ➔ 点击顶部【新建】按钮；
  * **快捷路径**：在【顶部导航栏】点击 **【DI管理】** ➔ 在【左侧导航栏】展开 **【其他】** 分组，点击 **【DI生成】**（进入 `Pages/DI_SC.cs`）。
- **3. 【DI主数据表单必填项清单与校验规则矩阵】**：

| 表单字段名称 | 数据库列名 | 必填约束 | 格式要求 / 校验规则 | 界面防差错拦截与合规说明 |
| :--- | :--- | :--- | :--- | :--- |
| **最小销售单元产品标识** | `ZXXSDYCPBS` | **必填** | 14位合规GTIN码或MA/AHM码 | 数据库唯一索引校验，禁止重复录入；提供【自动生成】按钮 |
| **产品通用名称** | `CPMCTYMC` | **必填** | 字符串 (≤100字) | 必须与医疗器械注册证或备案凭证上的品名完全一致 |
| **规格型号** | `GGXH` | **必填** | 字符串 (≤100字) | 具体申报规格，同品名多规格须逐一建立独立DI主档 |
| **产品标识编码体系** | `CPBSBMTXMC` | **必填** | 下拉单选 (GS1 / MA / AHM) | 默认选 GS1；编码结构校验器将基于此校验前缀与校验位 |
| **器械类别** | `QXLB` | **必填** | 单选 (1:器械, 2:体外诊断试剂) | 影响药监局报文数据节点分类，不可为空 |
| **注册证/备案号** | `YLQXZCBZBH` | **必填** | 标准注册号格式 | 如“国械注准2024xxxx”或“粤穗械备2023xxxx” |
| **企业名称** | `YLQXZCRBARMC`| **必填** | 注册人/备案人法定全称 | 自动默认当前企业名称，支持从基础资料选取 |
| **分类编码** | `FLBM` | **必填** | 10位国家分类代码 | 点击弹窗在 1852 项分类目录（`di_qxfl`）中模糊选取 |
| **是否与注册备案一致** | `SFYZCBAYZ` | **必选** | 默认“是” | 声明申报一致性 |
| **是否有本体标识** | `SFYBTZJBS` | **必选** | 默认“否” | 植入物或可复用手术器械本体打标选“是” |
| **使用前是否需要灭菌** | `SYQSFXYJXMJ` | **必选** | 是 / 否 | **红线拦截**：若选择“是”，则【灭菌方式】必选，否则禁止保存 |
| **灭菌方式** | `MJFS` | **条件必填** | 下拉框 | 仅在需灭菌时必选（环氧乙烷/辐照/湿热灭菌等） |

- **4. 操作步骤**：录入上述必填项 ➔ 点击【保存】入库 ➔ 自动进入 `di` 主数据表待申报。

### SOP-DI-02 多级包装规格与换算倍率配置规程 (右键增加包装标准操作)
- **1. 目的与业务场景**：规范产品的多级包装层级（单支 0 级、中盒 1 级、大箱 2 级、托盘 3 级）及倍率关系配置，支撑生产工单自动按比例折算赋码任务量，以及包装扫码防混淆与追溯图谱。
- **2. 真实系统操作路径与标准步骤**：
  * **第一步（进入DI库列表）**：在【顶部导航栏】点击 **【DI管理】** ➔ 在【左侧导航栏】展开 **【其他】** 分组，点击 **【DI库（生成）】**（进入 `Pages/DI_SC_List.cs` 列表页面）；
  * **第二步（右键唤起上下文菜单）**：在数据列表中找到目标最小销售单元产品（单品 DI）数据行，**鼠标右键点击该数据行**；
  * **第三步（选择增加包装）**：在弹出的右键菜单中点击 **【增加包装】**（注：右键菜单同时支持【删除包装】、【存储或操作信息】、【临床尺寸信息】）；
  * **第四步（抽屉录入并保存）**：系统界面右侧平滑滑出 **`DI_DevicePackage` (增加包装抽屉窗体)**，录入各层级包装参数并点击【保存】。
- **3. 【增加包装抽屉表单必填项清单与校验规则矩阵】**：

| 表单字段名称 | 数据库列名 | 必填约束 | 格式要求 / 校验规则 | 界面防差错拦截与合规说明 |
| :--- | :--- | :--- | :--- | :--- |
| **包装级别** | `CPBZJB` | **必填** | 下拉选择 (如“中包装”、“箱装”等) | 标识当前包装层级类型 |
| **包装产品标识** | `BZCPBS` | **必填** | 14位独立GTIN合规码 | 当前包装层的独立DI，包装指示符通常为1~8，不可与单品码相同 |
| **包装内含下级包装产品标识** | `BZNHXYJBZCPBS`| **必填** | 下拉选取直接下级 DI 码 | 严禁跨级包含；系统自动校验下级层级必须存在且有效 |
| **包装内含下级包装产品标识数量** | `BZNHXYJCPBSSL`| **必填** | 正整数 (>0) | 下级包装换算比例（如 1箱=10盒，填写 10；系统自动构建 1:N:M 换算链路） |
| **包装层级** | `BZDJ` | **系统自动计算** | 数字 (1, 2, 3...) | 系统根据依赖拓扑链自动递增识别层级（0级为单品，1级为中盒，2级为外箱等） |

- **4. 业务联动与质量红线**：
  * **生产工单下推**：生产单输入箱数时，系统根据 `di_devicepackage` 比例自动折算各级赋码任务量，无需人工逐级换算；
  * **赋码打印与包装关联**：扫码包装关联校验（`UDI_GLCX_Add.cs`）严格比对包装层级关系，禁止跨级装箱或错装。

## 模块二：UDI 生产排产、下推、打印与全景上查体系 (SOP-PROD 系列)

### SOP-PROD-01 医疗器械生产工单创建与必填项规程
- **1. 目的与页面**：下达车间生产工单，配置 PI 要素与计划数量。
- **2. 真实系统操作路径**：【顶部导航】点击 **【UDI管理】** ➔ 【左侧导航】展开 **【生产管理】** 点击 **【生产单列表】**（`Pages/UDI_SCD_List.cs`）➔ 点击【新增生产工单】进入 `Pages/UDI_SCD.cs`。
- **3. 【生产工单表单必填项清单与校验规则矩阵】**：

| 表单字段名称 | 数据库列名 | 必填约束 | 格式要求 / 校验规则 | 界面防差错拦截与合规说明 |
| :--- | :--- | :--- | :--- | :--- |
| **单据编号** | `scd_djbh` | **必填 (自动)** | `SCD+时间戳流水号` | 系统自动生成唯一单号，只读锁定禁止篡改 |
| **单据日期** | `scd_djrq` | **必填** | 日期格式 (yyyy-MM-dd) | 默认当天，支持手动调整 |

### SOP-LINK-01 生产单上下推与双向溯源（上查/下查）标准操作规程

- **1. 生产工单下推打印任务（下推 Push Down）**：
  * **入口**：在【生产单列表】（`Pages/UDI_SCD_List.cs`）勾选工单 ➔ 点击顶部【下推】下拉菜单。
  * **三种下推模式**：
    1. **【选中下推】**：勾选一条或多条明细行直接下推生成打印任务。若单据包含多级包装，自动调出层级弹窗；
    2. **【整单下推】**：无论当前勾选了哪一行，自动将该工单单号下的全部可下推明细整单下推；
    3. **【选中下推并编辑】**：仅支持单行操作，下推后立即自动打开打印单编辑明细页面（`Pages/UDI_DY.cs`）供现场调整参数。
  * **下推前置强拦截规则**：
    * 🔴 校验 1：生产单必须为【已审核】（`scd_djzt == "已审核"`），否则弹窗拦截：“这张生产单需要先审核通过，才能下推生成打印任务”；
    * 🔴 校验 2：生产单若为【已关闭】，禁止下推；
    * 🔴 校验 3：若选中的明细行状态已为【已下推】，系统弹窗警告防止重复生成任务；
    * 🔴 校验 4：跨单勾选拦截——勾选多行下推时，明细行必须属于同一张生产单。
  * **多级包装码折算选择弹窗（包装产品核心机制）**：
    * 若下推的产品含有包装层级（Depth > 0），系统拦截直接下推并自动弹出 **【生成下推任务层级确认】** 弹窗；
    * 弹窗实时计算并列出：大箱（2级）、中盒（1级）、单品（0级）以及各层级依换算倍率计算出的**任务生成数量**；
    * 操作员勾选目标层级后点击确认，系统批量写入 `udi_dy` 打印任务主表，并将工单状态标记为【已下推】。

- **2. 生产工单【上查】操作（Trace Up）**：
  * **入口**：在【生产单列表】勾选工单 ➔ 点击顶部【上查】下拉菜单（`dropdown_trace_up`）。
  * **操作模式**：
    * **【选中上查】**：反查当前选中行所绑定的来源销售订单；
    * **【整单上查】**：汇总当前工单单号所关联的所有销售订单明细。
  * **弹窗穿透内容**：系统根据 `xsd_detail_id` 强穿透销售单数据库，弹窗表格列出：
    `【来源销售单号】`、`【购货客户名称】`、`【产品名称】`、`【规格型号】`、`【销售数量】`、`【单据日期】`。

- **3. 生产工单【下查】操作（Trace Down）**：
  * **入口**：在【生产单列表】勾选工单 ➔ 点击顶部【下查】下拉菜单（`dropdown_trace_down`）。
  * **操作模式**：
    * **【选中下查】**：查询选中生产单行已下推生成的下游打印任务；
    * **【整单下查】**：查询该工单单号下派生出的全部包装层级打印任务。
  * **弹窗穿透内容**：系统根据 `scd_id` 关联 `udi_dy`，弹窗展示：
    `【任务编号】`、`【任务状态】`、`【DI产品标识】`、`【生产批号】`、`【是否启用序列号】`、`【生产日期】`、`【失效日期】`。

## 模块四：包装多级关联与总件数守恒体系 (SOP-PKG 系列)

### SOP-PKG-01 产线多级包装扫码关联与自动封箱规程
- **1. 目的与页面**：通过扫码枪建立“大箱 ➔ 中盒 ➔ 单支”的母子级联绑定拓扑（`udi_package` 表）。
- **2. 操作路径**：【UDI管理】➔【包装管理】➔【扫码关联】（`Pages/UDI_SMGL.cs`）。
- **3. 扫码必选要素与操作规程**：
  1. 扫描外包装箱码（大箱码），系统锁定母码并根据包装规格设定满箱阈值（如 10 盒）；
  2. 连续扫描 10 个子包装中盒码，界面动态更新装箱进度条；
  3. 达到设定容量，系统触发声光提示并**自动封箱**，生成包装层级绑定关系树；
  4. 严禁混入不同批号、不同品规的单品（系统遇混批自动弹红报警并拒绝关联）。

### SOP-PKG-02 拆装箱、退包装与在库件数严格守恒规程 (杜绝虚假调整单)
- **1. 核心业务法则**：
  * **在库物理总件数恒定守恒**：整包拆解或移出单品后，被移出的单品自动注册为在库散件行；
  * **彻底废除历史虚假单据**：严禁系统自动生成任何 `TZ*`（调整出入库）或 `HR*`（换入换出）单据；
  * **散件自动登账**：单品拆出时通过 `EnsureChildInInboundRecord` 自动注册进 `ck_inout_record`，重新打包入箱时通过 `RemoveFromInboundRecordWhenPacked` 自动合并消除；
  * **严禁虚假装箱**：禁止将未在库或无库存记录的单品强制装入在库箱，违者强行拦截。

### SOP-SD-02 销售订单四模式下推 UDI 生产工单与下查规程

- **1. 销售订单下推生产单（下推 Push Down）**：
  * **入口**：在【销售单管理】列表（`Pages/UDI_XSD_List.cs`）勾选订单 ➔ 点击顶部【下推】下拉菜单。
  * **四大下推操作模式**：
    1. **【选中下推】**：勾选选中的明细行，直接在后台生成 `udi_scd` 生产工单（状态为“创建”，业务状态“未下推”），无需弹窗编辑；
    2. **【整单下推】**：自动遍历当前销售单全部未下推明细，一键批量下推生成生产工单；
    3. **【选中下推并编辑】**：勾选单行明细，系统生成工单并立即弹出生产单编辑界面（`Pages/UDI_SCD.cs`）供补充车间、工艺备注；
    4. **【整单下推并编辑】**：整单下推后自动定位打开第一张生产工单编辑页。
  * **下推前置强校验拦截**：
    * 🔴 校验 1：销售单必须为【已审核】（`xsd_djzt == "已审核"`），否则提示：“请先审核通过这张销售单，然后再下推到生产单”；
    * 🔴 校验 2：销售单若已为【已关闭】，拦截下推；
    * 🔴 校验 3：明细防重校验——若明细下推状态已为 `xsd_detail_xt_status == "1"`，拦截下推：“你勾选的明细都已经下推过了，请重新选择其他明细”；
    * 🔴 校验 4：跨单拦截——禁止同时勾选属于不同销售单的明细进行下推。
  * **下推数据关联落地**：
    生成的生产工单自动回填客户名称、回写来源销售单号（`xsd_djbh`）与来源明细ID（`xsd_detail_id`），同时将销售明细标记为已下推。

- **2. 销售订单【下查】操作（Trace Down）**：
  * **入口**：在【销售单管理】列表勾选订单 ➔ 点击顶部【下查】下拉按钮（`dropdown_trace`）。
  * **操作模式**：支持【选中下查】与【整单下查】。
  * **穿透结果**：系统穿透查询由该销售单派生出的全部**生产工单列表（`udi_scd`）**，弹窗列出工单编号、工单状态、计划生产量、生产车间与建单时间。
