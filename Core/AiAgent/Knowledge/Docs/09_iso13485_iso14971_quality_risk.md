# ISO 13485:2016 质量管理体系与 ISO 14971 风险管理指南

## 一、 ISO 13485:2016 核心要求
ISO 13485 是国际医疗器械行业质量管理体系标准（对应中国 YY/T 0287 标准），核心要素包括：

1. **法规合规导向**：强调满足适用的法律法规要求（如中国 GMP、欧盟 MDR、美国 FDA QSR/QMSR）；
2. **文件化控制**：建立医疗器械文件（MDF，相当于 Device Master Record）、主文档、程序文件与作业指导书；
3. **设计和开发控制**：
   - 设计策划、输入、输出、评审、验证（Verification）、确认（Validation）、设计转换与设计更改；
4. **追溯性要求**：
   - 植入类器械必须追溯至所有使用的原材料、零部件及作业环境条件；
   - 必须记录产品发放的数量及每一批号/序列号的发运目的地。
5. **纠正与预防措施 (CAPA)**：建立从客户投诉、不合格品、审核发现到根因分析、验证有效性的闭环管理。

## 二、 ISO 14971:2019 医疗器械风险管理
风险管理贯穿医疗器械全生命周期（研发 -> 制造 -> 运输 -> 临床使用 -> 报废）：

1. **风险分析**：识别预期用途、合理可预见误用、危险（Hazard）、危险情况及可能导致的伤害（Harm）；
2. **风险评价**：基于严重度（Severity）和发生概率（Probability）评定风险等级；
3. **风险控制措施优先级**：
   - 优先级 1：通过安全设计实现固有安全（本质安全）；
   - 优先级 2：在器械本身或制造过程中采取防护措施（如报警、联锁）；
   - 优先级 3：提供安全性信息（说明书警告、警示标识、培训）。
4. **剩余风险综合评价**：所有单独剩余风险及整体综合剩余风险必须达到可接受水平（Benefit-Risk Ratio 获益大于风险）；
5. **生产和生产后信息收集**：持续收集上市后投诉与不良事件，动态更新风险管理报告。
