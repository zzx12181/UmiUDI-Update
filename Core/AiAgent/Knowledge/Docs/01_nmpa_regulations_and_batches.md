# 国家药监局医疗器械政策法规与 UDI 实施推进指南 (包含权威法条引证)

## 一、 核心上位法规体系与具体法条引证

1. **《医疗器械监督管理条例》（国务院令第739号，2021年6月1日起施行）**
   - **第三十八条**：医疗器械注册人、备案人应当建立医疗器械唯一标识制度，按照国家有关规定提交唯一标识相关数据，保证数据真实、准确、完整和可追溯。
   - **第四十五条**：医疗器械经营企业、使用单位应当建立并执行进货查验记录制度，查验并记录医疗器械唯一标识（UDI）。
   - **第八十九条第（三）项**：未按照规定建立并执行医疗器械进货查验记录制度（含未查验记录UDI）的，由药品监管部门责令改正，给予警告；拒不改正的，处1万元以上10万元以下罚款；情节严重的，责令停产停业，直至吊销许可证件。
   - **配套规章直接罚则（总局令第53号 第七十九条第(二)项）**：未按照国家实施医疗器械唯一标识的有关要求，组织开展赋码、数据上传和维护更新等工作的，由药监部门责令限期改正；拒不改正的，处1万元以上5万元以下罚款；情节严重的，处5万元以上10万元以下罚款。

2. **《医疗器械唯一标识系统规则》（国家药品监督管理局 2019年第66号公告）**
   - **第三条**：医疗器械唯一标识（UDI）由产品标识（DI）和生产标识（PI）组成。
   - **第七条**：产品标识（DI）为识别注册人/备案人、医疗器械型号规格和包装的唯一代码；生产标识（PI）包含生产批号、序列号、生产日期、失效日期等。
   - **第九条**：医疗器械注册人/备案人应当在产品上市销售前，将产品标识和相关数据上传至唯一标识数据库。
   - **第十一条**：医疗器械唯一标识应当与包装的包装层级相对应。最小销售单元及各级包装外表面必须印制或贴附唯一标识载体。
   - **第十四条**：医疗器械注册人/备案人应当保证唯一标识数据库数据的真实性、准确性、完整性。

3. **国家 UDI 数据库 (CUDID) 建设、填报与共享规范（官方行业标准与公告）**
   - **YY/T 1752-2020 《医疗器械唯一标识数据库基本数据集》**：规范注册人/备案人上传至 CUDID 的 50 余项 mandatory/optional 主数据字段定义。
   - **YY/T 1753-2020 《医疗器械唯一标识数据库填报指南》**：规定数据上报、修改、变更公示及校验规则。
   - **国家药监局 2020年第41号公告 《关于开放医疗器械唯一标识数据库共享服务的公告》**：规范全社会及医疗机构对 CUDID 数据的 API 接口查询与数据共享机制。

## 二、 全国三批 UDI 实施批次、公文文号与生效时间

| 批次 | 实施时间 | 权威公文文号 | 覆盖范围与合规要求 |
| :--- | :--- | :--- | :--- |
| **第一批** | 2021年01月01日 | 国家药监局《关于第一批实施医疗器械唯一标识工作的公告》（2019年第72号） | 高风险植入类医疗器械（心脏起搏器、人工关节、血管支架、骨科植入物等9大类）。上市前须完成 CUDID 申报并加贴条码。 |

## 三、 企业合规上报法定义务与处罚依据

1. **上市前数据发布**（依据《UDI系统规则》第九条）：在医疗器械产品正式上市销售前，注册人/备案人必须登录国家药监局 CUDID 数据库，完成 DI 及 50 余项产品扩展属性的首次发布；
2. **产品包装赋码**（依据《UDI系统规则》第十一条）：上市产品的最小销售单元及各级包装外表面，必须印制或贴附符合国家标准的 UDI 载体（GS1 DataMatrix 或 GS1-128）；
3. **流通与使用追溯**（依据《条例》第四十五条）：生产企业、经营流通企业及各级医疗机构需在进销存各节点扫码记录 UDI，实现“一码贯通、全程可溯”。
