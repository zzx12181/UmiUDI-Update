# 医疗器械生产赋码与合规质量故障智能排查指南 (SOP-QA/PROD)

> **核心原则**：本排查指南 100% 依据 UmiUDI & Drug 系统的真实业务功能模块、界面菜单路径与 GMP/GSP 质量管理规程编写。严禁使用任何虚构流程或非真实名词。

---

## 一、 生产赋码重码冲突报警排查与处置规程 (Duplicate Code Alarm SOP)

### 1. 现象描述
在车间产线打印、扫码关联装箱或成品入库扫码时，系统界面弹出**“当前序列号已存在 / 条码重复”**红色高亮报警，并强行阻断后续操作。

### 2. 真实系统排查定位路径（三步快速定位）

#### 第一步：进入【UDI追溯】或【包装管理 ➔ 关联查询】检索问题条码
- **操作路径**：点击顶部导航 **【UDI追溯】**，或在 **【UDI管理】➔【包装管理】➔【关联查询】（`UDI_GLCX`）** 中直接扫描或粘贴报警条码；
- **核查内容**：
  1. **检查生成来源**：查看该条码由哪张【打印单】生成，是否属于系统发号范围；
  2. **检查包装绑定状态**：查看该条码是否已被关联并封装到了某个大箱或中盒（`udi_package` 表），确认是单品码重复还是外箱包装码重复；
  3. **检查仓储流转状态**：查看该条码是否已在 **【仓库管理 ➔ 入库管理】（`CK_IN`）** 办理了产成品入库，或在 **【出库管理】（`CK_OUT`）** 执行了销售发货出库。

#### 第二步：在【打印列表】使用【上查】功能反查工单与批次
- **操作路径**：进入 **【UDI管理】➔【打印管理】➔【打印列表】（`UDI_DY_List`）**，定位到该条码所属的打印任务行，点击顶部工具栏 **【上查】**（`dropdown_trace_up`）；
- **穿透内容**：弹窗穿透呈现上游 **【生产工单单号】（`scd_djbh`）**、**【生产批号】（`scd_detail_ph`）**、计划生产量、车间及购货客户。

#### 第三步：核对【生产单列表】与流水号生成模式
- **操作路径**：进入 **【UDI管理】➔【生产管理】➔【生产单列表】（`UDI_SCD_List`）**；
- **核对要点**：核对工单是否被重复下推，检查该工单累计生成的打印任务数量是否超出工单计划产量。

### 3. 常见根因分析
1. **扫码枪连扫 / 操作员手抖重复扫码**：
   在 **【扫码关联】（`UDI_SMGL`）** 或 **【入库管理】（`CK_IN`）** 作业时，扫码枪灵敏度过高或触发连击，导致同一件产品的条码在毫秒级内被重复扫入，系统触发防重拦截报警；
2. **标签物理卡纸/损坏后未走受控重打流程**：
   产线遇打印机断纸、卡纸或标签褶皱打坏后，操作员未按 SOP 进入 **【重打印列表】（`UDI_CDY`）** 走受控补打，而是擅自新建了包含相同流水号区间的打印任务；
3. **工单或打印任务手动指定了重叠起始流水号**：
   在 **【打印列表】（`UDI_DY`）** 配置序列号发号模式时，人工修改了起始序列号数值，导致新任务的号段与历史已完成工单的号段发生区间重叠；
4. **包装关联跨箱混扫**：
   在 **【包装关联】（`UDI_BZGL`）** 或 **【扫码关联】（`UDI_SMGL`）** 中，误将已经装入前一个大箱的子件条码再次扫入了当前大箱。

### 4. 标准处置动作（按场景执行）
- **场景 A（物理标签损坏/卡纸补打）**：
  进入 **【UDI管理 ➔ 打印管理 ➔ 重打印列表】（`UDI_CDY_List`）**，选择对应记录提交补打申请，经车间主管审核后执行精准受控补打，同时将物理坏标当场剪角销毁；
- **场景 B（包装装箱扫错/混箱）**：
  进入 **【UDI管理 ➔ 包装管理 ➔ 关联查询】（`UDI_GLCX`）**，检索目标母箱，点击 **【单品移出】** 或 **【整包拆解】**（系统遵循件数守恒，自动将移出单品回退为在库散件台账），然后重新扫码装箱；
- **场景 C（已入库产品发现重码风险）**：
  在 **【仓库管理 ➔ 库存查询】** 中锁定该批次产品所在仓库与货位，执行实物隔离并走不合格品评审，严禁下推发货出库。

## 二、 条码无法识读与 GS1 校验位错误排查

### 1. 现象描述
扫码枪拒读、识读后内容乱码，或系统校验提示“GS1 Mod10 校验位错误”。

### 2. 真实系统排查路径与处置
1. **检查 DI 产品主档 GTIN-14 校验位**：
   进入 **【DI管理 ➔ 其他 ➔ DI库（生成）】（`DI_SC_List`）**，检查 14 位产品标识的最后一位校验位是否符合 GS1 Mod10 动态计算规则（奇偶权重 3:1）；
2. **检查标签模板设计与 AI 标识符括号**：
   进入 **【UDI管理 ➔ 打印管理 ➔ 标签设计】（`UDI_BQSJ`）**，核查二维码内容中是否错误地将人眼可见字符（HRI）的括号 `(01)`、`(10)`、`(17)`、`(21)` 编入了条码数据区（条码数据区应由 FNC1 / GS 分隔符分隔，严禁带物理括号）；
3. **核查日期格式**：
   UDI 条码中生产日期 `(11)` 与有效期 `(17)` 必须为 6 位数字纯格式（如 `260901` 代表 2026年09月01日），严禁出现横杠 `2026-09-01`；
4. **首检比对验证**：
   进入 **【UDI管理 ➔ 质量检验 ➔ UDI首检】（`UDI_SJ`）**，使用工业高精度扫码枪扫描实物样品，系统自动比对 DI、批号、效期、序列号一致性。

## 三、 首检未通过导致批量打印按钮锁定排查

### 1. 现象描述
在 **【UDI管理 ➔ 打印管理 ➔ 打印列表】（`UDI_DY` 明细页）** 中，右下角【打印选中】、【全部打印】、【范围打印】按钮被系统强行置灰锁定（`Enabled = false`），右上角显示黄色首检警告。

### 2. 规程原因与放行路径
1. **GMP 质量红线**：系统严格执行“未首检合格放行，严禁产线批量打印”的质量合规防线；
2. **解锁步骤**：
   - 点击明细页右上角 **【首检】** 按钮，自动打开 **【UDI首检】（`UDI_SJ`）** 窗体；
   - 质检员使用扫码枪扫描首件样品，系统自动校验条码与工单参数一致性；
   - 质检员确认外观质量、包装质量无误后，选择结论为 **“合格”** 并点击【保存】；
   - 系统自动回切打印明细页，关闭黄色警告，批量打印按钮立即解锁激活为绿色！

## 四、 销售订单下推生产单 / 生产单下推打印单失败排查

### 1. 现象描述
在【生产单列表】或【销售单管理】勾选数据行点击【下推】时，系统弹出拦截提示，无法生成下游单据。

### 2. 真实系统排查规则矩阵
1. **单据审核状态拦截**：
   - 销售单下推生产单：销售单状态必须为 **【已审核】（`xsd_djzt == "已审核"`）**；
   - 生产单下推打印单：生产单状态必须为 **【已审核】（`scd_djzt == "已审核"`）**；
   - 若状态为“创建”（保存态），必须由销售主管或车间主管在列表中点击 **【审核】** 审核通过后方可下推；
2. **单据关闭状态拦截**：已关闭（`已关闭`）的单据禁止再次下推；
3. **明细重复下推拦截**：若勾选的明细行状态已为【已下推】，系统弹窗警告防止重复派发任务；
4. **多级包装层级折算确认**：
   若生产工单对应的产品维护有多级包装（中盒、大箱），点击下推时系统会自动弹出 **【生成下推任务层级确认】** 弹窗，操作员须勾选目标层级（如勾选大箱，系统根据 1:N 比例自动折算箱数任务量），确认后方可完成下推。

## 五、 国家药监局 CUDID 申报对接错误码排查

- **错误 1001 - 机构未授权**：未在药监局对接申请中上传加盖公章的申请表 PDF，或授权接口密钥已失效；
- **错误 2005 - DI 校验失败**：GTIN-14 码未在 GS1 官方备案，或厂商识别代码与申报企业组织机构代码不一致；
- **错误 3008 - 必填扩展属性缺失**：如无菌器械在【DI库（生成）】未录入灭菌方式，或 IVD 试剂未提供储存温湿度上下限。

## 六、 多级包装规格与换算比例维护标准操作

- **标准系统操作路径**：
  1. 顶部导航点击 **【DI管理】** ➔ 左侧菜单展开 **【其他】** ➔ 点击 **【DI库（生成）】**（进入 `Pages/DI_SC_List.cs`）；
  2. 在数据表格中找到目标最小销售单元产品（单品 DI）数据行；
  3. **鼠标右键点击该数据行**，唤起右键菜单并点击 **【增加包装】**；
  4. 在弹出的【多级包装维护】抽屉窗体中录入包装层级名称、包装 DI 码（14位）、直接包含下级 DI 码及内含数量倍率（如 1 箱 = 10 盒，填写 10）；
  5. 点击【保存】即完成包装拓扑链绑定，生产下推与包装扫码防混淆即刻生效。
