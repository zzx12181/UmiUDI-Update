# 医疗器械 GMP 生产质量管理与 GSP 流通追溯规范 (包含权威法条引证)

## 一、 医疗器械生产质量管理规范 (GMP) 核心法定要求

依据《医疗器械生产监督管理办法》（国家市场监管总局令第53号）及《医疗器械生产质量管理规范》（国家食品药品监督管理总局公告2014年第64号）：

1. **唯一标识法定实施义务（依据总局令第53号 第三十六条）**
   - 医疗器械注册人、备案人、受托生产企业应当按照国家实施医疗器械唯一标识的有关规定，开展唯一标识赋码、数据上传和维护，保证信息真实、准确、完整和可追溯。

2. **生产记录与物料查验（依据规范2014年第64号 第三十六条、第四十四条）**
   - 企业应当建立物料进货查验记录制度，确保采购、验收、储存与领用全过程可追溯；
   - 每批产品均应当编制批生产记录，内容必须包含产品名称、规格型号、生产批号、生产日期、物料批号及关键工序记录。

3. **双向全过程追溯程序（依据规范2014年第64号 第六十六条）**
   - 生产企业应当建立产品追溯程序，规定追溯的范围、程度、标识和记录；
   - 在赋码环节配置自动校验防重装置，确保无重码、错码、漏码，实现从原材料采购、工艺流程、成品出库到最终放行的双向贯通。

## 二、 医疗器械经营质量管理规范 (GSP) 流通追溯强制要求

依据《医疗器械经营监督管理办法》（国家市场监管总局令第54号）及国家药品监督管理局最新版《医疗器械经营质量管理规范》（国家药监局公告2023年第153号，自2024年7月1日起施行）：

1. **采购进货查验强制记录 UDI（依据第153号公告 第三十五条）**
   - 企业在采购进货验收时，必须核验产品合格证明；
   - **按照国家规定实施医疗器械唯一标识的，必须查验并记录医疗器械唯一标识（UDI）**。

2. **销售出库记录强制包含 UDI（依据第153号公告 第四十七条）**
   - 企业销售医疗器械应当如实记录产品信息、流向客户、单价与销售日期；
   - **实施医疗器械唯一标识的，销售记录中必须包含医疗器械唯一标识（UDI）**。

3. **随货同行单必须标注 UDI（依据第153号公告 第五十条）**
   - 销售出库开具的随货同行单，必须加盖供货企业出库印章；
   - **实施医疗器械唯一标识的，随货同行单中应当完整打印医疗器械唯一标识（UDI）**。

4. **计算机信息系统自动追溯（依据第153号公告 第七十五条）**
   - 经营企业必须建立符合要求的计算机信息系统；
   - **实施医疗器械唯一标识的，企业应当在计算机信息系统中具备 UDI 数据采集、核对、记录和追溯功能，实现全过程可追溯。**

## 三、 医疗器械召回与风险穿透闭环控制

依据《医疗器械召回管理办法》（国家市场监督管理总局令第61号）：

1. **质量追溯体系与缺陷调查（依据第61号令 第十条）**
   - 注册人、备案人应当建立健全质量追溯体系；
   - **应当通过医疗器械唯一标识（UDI）、生产批号或者序列号等信息，准确确定缺陷医疗器械的生产批次、数量、销售流向和使用情况。**

2. **召回分级与精准通知（依据第61号令 第十三条、第十四条）**
   - 一级召回须在1日内发出召回公告，二级召回3日内，三级召回7日内；
   - 生产企业在实施召回时，必须根据医疗器械唯一标识（UDI）快速穿透在库、在途、在院全链路，精准通知相关单位与患者停用。
